TRANSPARENCY

Data provenance

PolarTwin separates verified public information from demonstration assumptions.

OUR RULE

Never present simulated telemetry as real station telemetry.

Because operational generator, fuel and logistics telemetry is not publicly available in the same form as the station metadata and weather observations, the prototype labels those values as simulated. This keeps the demonstration honest while still allowing the decision-support pipeline to be evaluated.
